# RevisionRoom kit

Payment link: https://www.paypal.me/M4RVlN

A lightweight client delivery/revision kit for short-form video agencies.

## Files

- `index.html`: sales page and public demo entry.
- `demo/client-portal.html`: editable client portal mockup.
- `templates/client-brief.md`: brief intake template.
- `templates/revision-rules.md`: revision rules clients can accept before work starts.
- `templates/email-sequence.md`: client emails for brief, V1, feedback chase and final delivery.
- `tracker.csv`: spreadsheet-compatible delivery tracker.
