# RevisionRoom kit

A ZIP of editable files for short-form video editors who are tired of losing client feedback across email, DMs and Drive.

## What is inside

- **Client status page (HTML)** — shows each video project, its status, editor, due date and revision notes. Edit the HTML file and host it anywhere (Google Drive, Notion, GitHub Pages, your own site).
- **Project tracker (CSV)** — a simple spreadsheet: client, video, status, editor, due date, asset links and next action. Open in Excel, Google Sheets or Numbers.
- **Brief intake template** — what you send every client before the first edit. Reduces vague requests.
- **Revision rules** — share with clients before work starts: "two rounds included; a new hook is a new video."
- **Email/message sequence** — 5 ready-to-copy messages: brief request → V1 delivery → feedback chase → final delivery → next-batch upsell.
